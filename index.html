01 / GETTING STARTED

What is Multithreading?

First, understand the basic idea behind threads in Java.

01

Definition

Multithreading is a Java feature that allows multiple threads to execute tasks concurrently within a single process. Threads share the process's memory and resources, while each thread has its own execution stack.

↗

Thread

A thread is a lightweight unit of execution inside a process.

▦

Process

A process is a running instance of a program with its own resources.

⌁

Concurrency

Multiple tasks make progress during overlapping periods of time.

Remember: Concurrency does not always mean tasks run at the exact same instant. Parallel execution depends on the available processor cores and runtime scheduling.

Advantages and Disadvantages

✓ Advantages

  • Helps applications stay responsive.
  • Supports concurrent task execution.
  • Can improve CPU utilization.
  • Useful for background work.

! Disadvantages

  • Debugging can be difficult.
  • Race conditions may occur.
  • Shared data needs careful coordination.
  • Too many threads add overhead.

03 / THREAD LIFE CYCLE

Thread Life Cycle.

Java defines six thread states through the Thread.State enum.

01

NEW

Thread object is created, but start() has not been called.

02

RUNNABLE

Thread is eligible to run or is running. Java combines these ideas in this state.

03

BLOCKED

Waiting to acquire a monitor lock.

04

WAITING

Waiting indefinitely for another thread's action.

05

TIMED_WAITING

Waiting for a specified time, for example with sleep().

06

TERMINATED

The thread has finished its execution.

Interview point: Java has no separate RUNNING value in Thread.State. A thread executing on the CPU is still reported as RUNNABLE.

04 / PRACTICAL JAVA

Create Your First Thread.

Read the code, understand it, then execute it in VS Code.

EXAMPLE 01

Using the Thread class

Extend Thread and override the run() method. 

class MyThread extends Thread {
    public void run() {
        for (int i = 1; i <= 5; i++) {
            System.out.println("Child Thread: " + i);
        }
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t = new MyThread();
        t.start();

        for (int i = 1; i <= 5; i++) {
            System.out.println("Main Thread: " + i);
        }
    }
}

How does it work?

  1. extends Thread creates a custom thread class.
  2. run() contains the task to execute.
  3. new MyThread() creates a thread object.
  4. start() asks the JVM to start a new thread, which then invokes run().
  5. The main thread and child thread may interleave their output.
ILLUSTRATIVE OUTPUT 
Main Thread: 1
Child Thread: 1
Child Thread: 2
Main Thread: 2
...

Output order may change each time. This is only one possible ordering.

EXAMPLE 02

Using the Runnable interface

Runnable represents a task that can be passed to a Thread. 

class MyTask implements Runnable {
    public void run() {
        for (int i = 1; i <= 5; i++) {
            System.out.println("Task: " + i);
        }
    }
}

public class Main {
    public static void main(String[] args) {
        MyTask task = new MyTask();
        Thread t = new Thread(task);
        t.start();

        System.out.println("Main method continues");
    }
}

Why use Runnable?

  • Separates the task from the Thread object.
  • Your class can still extend another class, because Java supports only single class inheritance.
  • Runnable is widely used with executors and thread pools.
EXAMPLE 03

start() vs run()

class Demo extends Thread {
    public void run() {
        System.out.println("Executing: " +
                           Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        Demo t = new Demo();

        t.run();   // Runs directly on the main thread
        t.start(); // Starts a new thread
    }
}
OUTPUT 
Executing: main
Executing: Thread-0

The default child-thread name is commonly Thread-0 for this first thread.

05 / IMPORTANT RULES

Must-Know Methods.

start()

Starts a new thread of execution.

run()

Contains the task logic. Calling it directly does not start a new thread.

sleep(ms)

Pauses the current thread for a duration, subject to scheduling.

join()

Waits for a thread to finish.

currentThread()

Returns the currently executing Thread object.

getName()

Returns the thread's name.

Important: A thread can be started only once. Calling start() again on a terminated thread throws IllegalThreadStateException.

QUESTION 01 / 05

What is a thread in Java?

Quick Interview Questions

1. What is multithreading?

It allows multiple threads to make progress concurrently within a process.

2. What is the difference between start() and run()?

start() initiates a new thread; a direct call to run() executes like an ordinary method on the current thread.

3. Can Java extend multiple classes to create threads?

No. A class can extend only one class, so implementing Runnable is another common approach.

4. What is a race condition?

It happens when the result depends on the unpredictable timing of concurrent access to shared state.

5. Does multithreading always make a program faster?

No. Scheduling, synchronization, task type, and overhead affect performance.
